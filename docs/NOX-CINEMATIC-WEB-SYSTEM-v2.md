# NOX Cinematic Web System v2

## 1. 北極星

NOX 的高階網站不是「可以用滑鼠亂轉的 3D 展示器」，而是「可以由使用者控制時間的電影」。每一段都要先回答四個問題：

1. 這一鏡要讓觀眾感受到什麼？
2. 畫面主體在構圖中佔多少、何時被揭露？
3. 使用者在這一段需要控制空間，還是只需要控制進度？
4. 用哪一層完成最划算：DOM、影像、影片、WebGL，或混合？

參考基準是使用者提供的約 23.5 秒 FULAN VILLA 錄影。可學的是鏡頭、空間揭露、節奏、排版與收尾；不可假設錄影裡的所有畫面都是即時 3D。

## 2. 決策優先序

```text
品牌目的 > 故事 > 分鏡 > 構圖 > 鏡頭 > 資產 > 媒介分工 > 效能 > 技術庫 > 特效
```

任何工具選型若發生在分鏡之前，都必須視為暫定。任何特效若不能強化故事、視線或操作回饋，預設刪除。

## 3. Production gates

| Gate | 必須產出 | 通過條件 |
|---|---|---|
| 0 定義 | 一句體驗命題、目標客群、裝置範圍 | 不用技術名詞也能說清楚網站價值 |
| 1 參考 | 可追溯參考清單與逐鏡拆解 | 每個借用元素都說明用途，不只是「有質感」 |
| 2 美術 | Art Bible、素材清單、授權狀態 | 第一屏靜態截圖已可成立 |
| 3 分鏡 | 15–20 秒鏡頭表與 0→1 timeline | 每 5–10 秒至少有一次有意義的視覺事件 |
| 4 Vertical slice | 一個完整揭露、主體近景、一次過場 | 與參考並排比較後仍達標 |
| 5 擴張 | 模組化章節、載入、效能、fallback | 新章節不破壞時間軸與手機構圖 |
| 6 出貨 | 固定檢查點、真機結果、build ID | 正式網址與驗收 commit 完全一致 |

Gate 未通過就停在當層修正，不以「先做完再調」跨過品質問題。

## 4. 預設技術角色

| 層 | 預設 | 只負責 |
|---|---|---|
| 應用 | React／Next.js 或適合專案的框架 | 路由、資料、可存取性、DOM 內容 |
| 3D | Three.js／React Three Fiber + Drei | 空間、相機、材質、即時互動 |
| 主時間軸 | GSAP + ScrollTrigger | 全站 scroll progress 與跨層同步 |
| Scroll 輸入 | Lenis | 輸入平滑；不得另建第二時間軸 |
| 鏡頭製作 | Curve／Drei MotionPathControls；必要時 Theatre.js | 可視化 keyframe、focus 與 timing |
| 資產 | glTF Transform、gltfjsx、Draco 或 Meshopt、KTX2 | 壓縮、去重、轉換、runtime 載入 |
| 局部 UI | CSS／Motion 或 Anime.js 擇一 | 不得控制主場景或主 scroll timeline |

`r3f-scroll-rig` 只有在 DOM 與單一 WebGL Canvas 對位是核心需求，且瀏覽器測試通過時才採用。Spline 適合快速原型或已擁有的場景，不是長期可控性的預設答案。

## 5. 媒介分工

| 需求 | 預設媒介 |
|---|---|
| SEO、可讀文字、表單、導覽、CTA | DOM |
| 只需電影感、不需改變視角 | 預渲染影片或影像序列 |
| 布料、毛髮、複雜流體、大量破碎 | 影片，除非即時反應是產品核心 |
| 真正需要視角、光影、空間或物件狀態互動 | WebGL |
| 既要電影品質又要輕互動 | 影片／影像背景 + WebGL 前景 + DOM chrome |

判斷句：移除即時 3D 後，使用者是否失去必要的控制或理解？若沒有，優先不用即時 3D。

## 6. 標準 0→1 敘事骨架

| Progress | 鏡頭功能 | 典型事件 |
|---|---|---|
| 0.00–0.15 | Establishing | 世界、品牌與尺度成立 |
| 0.15–0.35 | Dolly in | 朝入口或主體前進，建立期待 |
| 0.35–0.55 | Threshold | 遮擋、轉暗、穿越或 match cut |
| 0.55–0.75 | Main reveal | 主空間或英雄物件近景 |
| 0.75–0.90 | Side reveal | 第二層資訊、材質、光色或空間轉向 |
| 0.90–1.00 | Resolve | 品牌、CTA、聲音與動作收束 |

比例只是起點；實際長度由鏡頭事件決定，不以固定 `vh` 硬撐。

## 7. Definition of Done

- 沒有模型時，第一屏的排版與構圖仍然成立。
- 逐鏡表可以對應到程式 timeline、素材檔與 QA 截圖。
- 每個畫面都標示由 DOM／影像／影片／WebGL 哪一層負責。
- 主時間軸只有一個；scroll callback 不執行重型計算或 layout thrash。
- 手機有獨立構圖與降級策略，不只是降低 DPR。
- 所有素材有來源、授權、用途與版本紀錄。
- 固定 0%、25%、50%、75%、100% 截圖和真機測試通過。
- 正式部署可追溯到 commit、build ID 與測試紀錄。

## 8. 禁止的捷徑

- 先拼 UI 元件，再補品牌語言。
- 用霧、顆粒、Bloom 或全屏模糊掩飾素材不足。
- 六章都使用同一走廊、同一色溫，只更換文字。
- 在 JSX 內嵌大型 Base64 GLB 作為正式交付。
- 在每一區建立獨立 Canvas 或獨立 RAF。
- 未取得授權證據就把 AI／第三方素材放進客戶專案。
- 只驗證「能開、能捲、模型有出現」就宣稱完成。
