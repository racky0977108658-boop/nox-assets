# Art Direction 與參考拆解

## 1. 參考不是 mood，而是證據

每個參考都要記錄 URL／檔名、擷取日期、時間碼、想借用的元素與禁止照抄的部分。影片逐鏡表至少包含：

| 欄位 | 問題 |
|---|---|
| 時間 | 這一鏡從幾秒到幾秒？ |
| 主體 | 畫面主體是什麼，約佔畫面幾成？ |
| 鏡頭 | Dolly、pan、orbit、crane、cut、match cut 或靜止？ |
| 景別 | 遠景、中景、近景、特寫？ |
| 遮擋 | 什麼在前景形成深度或轉場？ |
| 光色 | 主光方向、色溫、黑位與高光如何變化？ |
| 媒介 | 可確認是 DOM、影片、WebGL，還是只能標示未知？ |
| 聲音 | 音樂、環境、撞點、靜默如何配合？ |
| 功能 | 這一鏡在故事裡的工作是什麼？ |

看不出的技術必須標示「未知」，不得由錄影外觀推斷整站都是即時 3D。

## 2. Art Bible 必填

- 一句世界觀與三個情緒詞。
- 色票：背景、文字、主光、點綴、警示，各自使用比例。
- 材質：最多三個主材質族，例如石材／金屬／玻璃。
- 光源：主光方向、陰影硬度、環境色、曝光範圍。
- Typography：Display、Body、Mono 的用途與中文字 fallback。
- UI chrome：邊框、刻度、游標、章節計數器與 CTA 的規則。
- Motion：快慢層級、easing、模糊、縮放與離場方式。
- 禁用清單：無目的粒子、彩色漸層、過量 glow、連續彈跳、9–11px 主要操作字。

第一屏要先以靜態 frame 驗收。若靜態畫面不成立，動畫不會把它救成高級網站。

## 3. 資源分級

| 類別 | 可用來源 | 使用方式 |
|---|---|---|
| 完整節奏參考 | Landing Love、Motion Sites、實際品牌網站錄影 | 拆鏡頭與事件密度，不複製品牌 |
| 資訊架構 | SaaSpo、Curations Supply | 研究版面、內容順序與 CTA |
| UI 零件 | 21st.dev、Magic UI、Origin 類元件庫 | 只取局部解法，需重新套用 NOX 視覺語言 |
| 字體探索 | Uncut、字體 foundry、Google Fonts | 使用前逐款確認網頁嵌入與商用授權 |
| 3D 技術 | Three.js／pmndrs 官方範例 | 學 API 與架構，不把 demo 當 production template |
| 3D 資產 | Poly Haven、pmndrs market、Khronos sample、已授權的 Sketchfab | 登記來源、作者、license 與修改紀錄 |

上述服務可能改版或變更授權。每次實際使用都要重新打開官方頁面確認，不依賴本文件的舊描述。

## 4. Typography 原則

- Display 字體負責品牌，不承載長文或主要操作。
- 正文繁中必須有完整 CJK fallback；不得因追求西文字型造成缺字。
- Mono 只用於座標、章節、時間碼與技術標籤。
- 主要操作與重要資訊在手機上原則上不小於 14px；微型標籤也必須通過對比與實機可讀性。
- 字距、行高與換行要在 390px、768px、1440px 三個寬度驗收。

## 5. 參考轉化規則

一個參考只能借一到兩種核心語法。把來源轉成 NOX 設計時，要改變至少：內容、比例、節奏、材質與品牌語氣；不可把多個流行元件直接拼成 Resource Soup。
